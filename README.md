## 📌 Project Overview

The **HR Analytics Dashboard** is an end-to-end Tableau project that helps HR teams and business leaders monitor workforce performance and employee attrition through interactive visualizations.

This dashboard converts raw employee data into actionable HR insights, making it easier to identify attrition trends, workforce distribution, employee satisfaction, and hiring opportunities.

### 🎯 Business Goal

Help HR managers make **data-driven decisions** related to:

- Employee Retention
- Workforce Planning
- Recruitment Strategy
- Employee Satisfaction
- Organizational Performance

---

## 🎯 Objectives

- 📊 Analyze employee attrition trends.
- 👥 Monitor workforce demographics.
- 💼 Evaluate department-wise employee turnover.
- 😊 Understand job satisfaction across roles.
- 🎓 Analyze education field impact on attrition.
- 📈 Create interactive HR dashboards for decision-making.

## 🧹 Data Cleaning Process

Before creating the dashboard, the dataset was cleaned in Excel.

| ✔️ Cleaning Task | Description |
|-----------------|-------------|
| Remove Duplicates | Eliminated duplicate employee records. |
| Handle Missing Values | Removed or updated null values where appropriate. |
| Data Formatting | Corrected date, numeric, and categorical formatting. |
| Text Cleaning | Used Trim, Proper Case, Lower/Upper Case. |
| Find & Replace | Standardized inconsistent values. |
| Spell Check | Corrected text inconsistencies. |
